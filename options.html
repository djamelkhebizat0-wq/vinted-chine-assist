Règles locales (sans API Vinted)

Planification (URL + date)

Pas de Cloud 24/7 dans l’extension

Les alarmes, le CRM et la négo s’exécutent uniquement tant que Chrome est ouvert (et, pour les content scripts, sur vinted.fr / vinted.com). Il n’y a pas de serveur, pas de file d’attente distante, pas de bot qui tourne la nuit.

Pour un vrai 24/7 il faudrait un backend (session, files, légalité CGU) — voir docs/ARCHITECTURE-CLOUD.md.

Pas d’application native iOS / Android

Cette page est responsive (mobile Chrome / Kiwi). Chrome Android officiel n’installe pas les extensions MV3. Un PWA autonome n’existe pas ici : ce n’est pas une app stores.

Avertissement

Outil d’aide à la rédaction et au suivi personnel. Pas de spam, pas de multi-comptes automatisés, pas de contournement de ban. Respectez les CGU Vinted.
